# Fahrt ist die Atombewegung

Eine **Fahrt** ist genau eine Bewegung eines Fahrzeugs: ein Start, ein Ziel, ein Nutzungstyp, ein Zweck, Start- und End-Kilometerstand. Eine Tageskette mit Zweckwechsel (Baustelle A → Döner → Baustelle A → Kunde B) ist eine Folge von Fahrten. Begründung: BFH verlangt Zweck, Ziel und Geschäftspartner je Fahrt aus dem Buch selbst (st. Rspr., zusammengefasst z. B. BFH 15.7.2020 – III R 62/19 unter Verweis auf VI R 33/10). Abrechnung hängt an einer Kund:in je Teilstrecke. Ein Datensatz „Tour mit Stopps“ oder „ein Tag, eine Summe“ macht gemischte Zwecke und zwei Kund:innen unverifizierbar.

## Alternatives considered

- **Tour mit Wegpunkten** in einer Hülle: bequem am Freitag, unlesbar in der Prüfung.
- **Ein Tag = ein Eintrag:** verworfen — das ist kein Fahrtenbuch.
