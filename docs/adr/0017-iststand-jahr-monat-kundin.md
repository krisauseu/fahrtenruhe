# Iststand: Jahr, Monat, Kund:in — dieselbe Addition

Der Iststand ist jederzeit sichtbar. Default ist das laufende Buchjahr je Fahrzeug (km je Nutzungstyp, Quote, Band, Pauschalen-Spalte). Filter sind Monat, Zeitraum und Kund:in. Die Zahlen sind dieselben Additionen wie im Jahresnachweis. Es gibt keine Hochrechnung auf den 31.12. Begründung: Ohne laufende Sicht kippt die Quote unbemerkt. Eine Hochrechnung ist keine Zahl aus dem Buch (ADR-0005: die Zuordnung ist ein Jahresergebnis, kein Forecast).
