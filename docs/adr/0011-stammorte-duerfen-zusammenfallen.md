# Stammorte dürfen zusammenfallen

Wohnung und erste Tätigkeitsstätte sind konfigurierbare Stammorte. Sie dürfen dieselbe Adresse sein. Der Nutzungstyp Wohnung–Tätigkeitsstätte wird in der UI nur angeboten, wenn die Orte verschieden sind. Die Klassifikation einer Fahrt bleibt manuell. Begründung: Der Solo-Regelfall ist das Büro in der Wohnung; dann ist jede Fahrt nach draußen betrieblich, nicht Pendeln. Geofence würde einen Nutzungstyp raten, den nur die Nutzer:in verantworten kann.

## Alternatives considered

- **Tätigkeitsstätte immer ≠ Wohnung:** ignoriert Homeoffice.
- **Keine Stammorte:** korrekt, aber langsam in der Einfahrt.
