# AGPL-3.0, Zettelruhe-Auth, Verfahrensdokumentation ohne Zertifikat

Fahrtenruhe steht unter AGPL-3.0. Login, httpOnly-Session und Mitgliedschaft folgen dem Zettelruhe-Muster (in v1 UX dünn, Rolle Lesen bleibt im Modell für späteres Steuerberatungs-Lesen). Es gibt eine Verfahrensdokumentations-Vorlage, kein bezahltes GoBD-Zertifikat. Begründung: Derselbe Host, dieselbe Persona, derselbe Copyleft-Trade-off wie Zettelruhe. Ohne Mitgliedschaft im Schema müsste die Lese-Rolle nachgerüstet werden. Ein Verkäufer-Zertifikat ersetzt VI B 37/23 nicht.

## Alternatives considered

- **Proprietär / anderes Auth:** bricht den Zwilling.
- **Genau ein Login, kein Mitgliedschafts-Schema:** spart Tabellen und kostet den Steuerberatungs-Lesezugriff.
