# Kilometerstand in ganzen Kilometern

Start, Ende und Strecke sind ganze Kilometer. Die UI rundet nicht still; eine Eingabe mit Nachkommastelle muss vor dem Speichern auf eine ganze Zahl festgelegt werden. Begründung: Der Zähler im Fahrzeug zeigt ganze km. Zehntel sind die Genauigkeit einer Abrechnungszeile (Zettelruhes `km`), nicht eines Fahrtenbuchs. Scheingenauigkeit erzeugt künstliche Lücken.
